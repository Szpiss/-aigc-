# 词魂

词魂是一个微信小程序项目，面向英语词汇学习、单词对战、学习数据统计和复习安排。项目使用微信小程序原生框架、TypeScript、微信云开发、云函数和云数据库实现，适合作为小程序课程设计或 AIGC 辅助学习产品原型。

## 主要功能

- 词汇学习：日常练习、词汇检测、选项练习、认识/不认识练习。
- 单词对战：随机匹配、好友对战、人机对战。
- 生词与弱词：记录错词、不认识词和提示使用情况。
- 数据看板：展示学习次数、词数、正确率、弱词榜和对战记录。
- 学习助手：根据学习记录、弱词和对战数据整理学习建议与复盘内容。
- 设置与关于：题量、声音、发音、震动、清理数据等基础配置。

## 数据流

1. 用户完成学习或对战。
2. 前端调用云函数写入学习记录或对战记录。
3. 云函数更新用户数据、学习统计、掌握度和计划数据。
4. 首页、数据看板、弱词榜和学习助手读取最新结果。

## 本地运行

1. 使用微信开发者工具打开项目根目录。
2. 确认 `project.config.json` 中的小程序和云函数目录配置正确。
3. 在微信开发者工具中构建小程序 npm。
4. 上传并部署 `cloudfunctions/server` 云函数。
5. 准备 `user`、`book`、`word`、`userWord`、`combatRecord`、`learningRecord`、`learningData`、`wordMastery`、`learningPlan` 等集合。

## 检查清单

- 页面可正常进入和返回。
- 学习完成后首页和数据看板能刷新。
- 对战完成后总局数、胜利次数和对战记录能更新。
- 词库不足时页面有明确提示。
- 小屏设备下顶部栏、按钮和卡片不遮挡。
- 云函数部署后接口无明显报错。
