# 词魂：基于 AIGC 与自适应调度的英语词汇学习对战小程序

词魂是一个基于微信小程序原生框架与云开发能力实现的英语词汇学习与单词对战产品。项目面向英语词汇学习动力不足、反馈滞后、AI 工具与学习数据割裂的问题，构建了“词汇学习 -> 单词对战 -> 数据采集 -> 自适应调度 -> AI Agent 复盘”的闭环式学习系统。

当前分支：`feature/ui-modernization`

远程仓库：[https://github.com/Szpiss/-aigc-.git](https://github.com/Szpiss/-aigc-.git)

## 1. 项目定位

项目核心包装为：

**基于 AIGC 与自适应调度的英语词汇学习对战小程序**

系统通过词汇学习积累基础输入，通过单词对战提供即时反馈，通过数据看板展示学习和竞技表现，再由 AI Agent 结合学习记录、弱词榜、学习计划和对战数据生成个性化学习建议与对战复盘。

## 2. 核心功能

### 首页

- 展示用户头像、昵称、词力值、总对战局数、累计胜利。
- 展示词汇学习模式、提示卡、当前词书、核心功能入口。
- 核心入口包括单词对战、AIGC 学习助手、数据看板、词汇学习、生词本。
- 底部保留更多服务入口，例如设置、建议反馈等。

### 单词对战

- 支持随机匹配、好友对战、人机对战。
- 每题倒计时，答对得分与反应速度相关。
- 错词会进入生词 / 弱词沉淀，用于后续学习计划。
- 对战结束后写入 `combatRecord`，并同步学习数据、对战统计和用户成长数据。

### 词汇学习

词汇学习已拆分为两个明确场景：

- **日常练习**：适合长期刷词，不因答错提前结束。
- **词汇检测**：适合阶段性检测，可设置错误上限。

两种场景都支持两种方式：

- **单词选项**：从选项中选择正确释义。
- **认识 / 不认识**：自评掌握情况，可查看释义。

日常练习词数：

- 25 词
- 50 词
- 100 词

词汇检测配置：

- 检测词数：25 / 50 / 100
- 错误上限：错 3 / 5 / 10 个结束
- 结束条件：达到错误上限，或完成所选检测词数

如果词库不足，系统会提示当前可用词数，并按实际可用词数完成本轮学习或检测。

### 数据看板

- 展示学习汇总、学习趋势、弱词榜、对战汇总、最近对战记录。
- 保持“学习”和“对战”两个一级统计体系。
- 兼容旧学习记录，旧记录没有学习模式字段时仍可正常统计。

### AI Agent / 英语学习助手

AI Agent 页面现在统一为四个模块：

- 英语学习助手
- 词汇学习
- 对战复盘
- 学习建议

页面使用统一顶部栏：

- 左侧菜单按钮
- 中间当前页面标题
- 右侧返回首页按钮

点击左侧菜单会打开抽屉导航，四个模块可直接切换，当前模块高亮。顶部栏会根据微信状态栏和胶囊按钮位置计算安全距离，避免遮挡和重叠。

英语学习助手模块已简化为纯聊天页：

- 保留聊天消息区
- 保留输入框
- 删除快捷提示词 chips
- 删除复杂入口卡片和 Insight Panel

对战复盘和学习建议模块只保留核心内容卡片和必要操作按钮。

- 首页在 `onShow` 时刷新用户信息。
- 学习结束后同步词力值 / 经验值。
- 对战结束后同步总局数、胜利次数、词力值。

- 数据看板和文档中的学习体系保持为“学习 / 对战”两个大类。

### 3.4 词汇学习模式与流程重构

- 从短流程学习改为“日常练习 / 词汇检测”两类场景。
- 日常练习支持 25 / 50 / 100 词，严格按选择词数完成。
- 词汇检测支持 25 / 50 / 100 词，并支持错误上限 3 / 5 / 10。
- 认识 / 不认识模式中，“查看释义 / 认识 / 不认识”三个操作同时可见。
- 每进入新词时自动重置释义显示状态。
- 错词和“不认识”词继续进入复习 / 生词逻辑。

### 3.5 词数缩小问题修复

已修复日常练习选择 25 / 50 / 100 后实际变成 4 / 10 / 20 的问题。

根因：

- 云函数 `generateLearningPlan` 会按弱词、巩固词、新词比例生成计划。
- 当用户弱词和巩固词样本不足时，只返回了新词比例部分。
- 25 / 50 / 100 的 20% 近似就是 4 / 10 / 20，导致前端实际练习数量被缩小。

修复方式：

- 云函数生成计划时，如果弱词 / 巩固词不足，用新词补齐到请求词数。
- 前端初始化会话时，如果计划词不足，会继续随机抽样补齐到目标词数。
- 如果词库本身不足，会明确提示实际可用词数。

### 3.6 AI Agent 工作台减法式重构

- 删除横向 4 按钮导航，避免和微信胶囊按钮冲突。
- 改为顶部栏 + 抽屉菜单导航。
- 删除 Agent 页面内部重复入口按钮。
- 删除快捷提示词 chips。
- 删除未使用的 `agentInsightCards` 组件。
- `agent-ui` 组件宽度从固定 `750rpx` 调整为自适应 `100%`，避免嵌入卡片后横向溢出。
- 支持通过 `hideQuestions` 隐藏 agent-ui 内部推荐问题。

### 3.7 AIGC 能力聚焦

- AIGC 页面不再像普通聊天工具堆功能块。
- 对战复盘模块聚焦最近对战结果、正误情况、复盘建议。
- 学习建议模块聚焦学习记录、弱词和下一步安排。
- 词汇学习模块只保留学习入口和学习流程，不再显示 Insight Panel、学习状态、统计卡片等额外内容。

### 3.8 设置页和首页入口调整

- 设置入口从首页用户信息卡片中移出，统一放到底部更多服务区。
- 设置页不再放“词汇学习模式”配置项。
- 删除“关于词魂”等不适合放在设置页的项目介绍内容。
- 首页保留底部反馈 / 更多服务区域。

### 3.9 中文乱码修复

- 修复多个页面中用户可见的中文乱码。

## 5. 关键业务流程

### 5.1 学习数据流程

1. 用户进入词汇学习。
2. 选择日常练习或词汇检测。
3. 选择词数和学习方式。
4. 系统生成或补齐目标词表。
5. 用户完成学习或检测。
6. 写入学习记录和学习统计。
7. 更新词力值、经验值和弱词数据。
8. 首页和数据看板读取最新数据。

### 5.2 对战数据流程

1. 用户选择随机匹配、好友对战或人机对战。
2. 对战结束后写入 `combatRecord`。
3. 更新总局数、胜利次数、词力值和经验值。
4. 错词进入生词 / 弱词体系。
5. 数据看板和 AI Agent 对战复盘读取最新对战数据。

### 5.3 自适应调度流程

1. 系统读取 `wordMastery`。
2. 优先选择低掌握度词汇。
3. 结合巩固词和新词生成 `learningPlan`。
4. 样本不足时用新词补齐请求词数。
5. 词汇学习优先使用计划词，不足时前端继续随机补齐。

### 5.4 Agent 分析流程

1. Agent 拉取学习计划、弱词榜、学习报告。
2. 对战复盘模块额外拉取最近对战记录。
3. 根据真实数据生成学习建议或对战复盘。
4. 数据不足时展示友好空状态和启动建议。

## 6. 数据模型

核心云数据库集合：

- `combatRecord`：对战记录
- `learningRecord`：学习记录
- `learningData`：学习和对战日统计
- `wordMastery`：单词掌握度
- `learningPlan`：自适应学习计划

## 7. 技术栈

- 前端：微信小程序原生框架（WXML / WXSS / JS / TS）
- 云开发：CloudBase 云函数 + 云数据库
- 状态管理：wxMiniStore
- 路由：wxapp-router
- 事件管理：mitt
- AIGC：腾讯云开发 AI 模块 + `agent-ui` 组件

## 10. 手动验收建议
